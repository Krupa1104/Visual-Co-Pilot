# Visual Co-Pilot: A Visual Question Answering (VQA) System for Aviation

Capstone Project — Phase 3
Team members: Krupa R, Madhumitha N V, Krithika A, M Asritha

## Structure
- `cockpit/` branch — cockpit VQA module (gui, process, test — code only; dataset folders kept local, not versioned)
- `radar/` branch — radar module (separate, not yet integrated)

## Note on datasets
Raw dataset folders (climb, consolidated, engine_off, level_flight, takeoff_roll, taxi) are ~7.6GB and excluded from git via .gitignore. Available locally / on request.
